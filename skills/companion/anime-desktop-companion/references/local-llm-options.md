# 桌宠本地 AI 大脑选型（Local LLM Options）

> 适用：自研 Harness 的 LLM 模块（方案总成 §4）。全部走本地 Ollama / llama.cpp，零运行成本、隐私优先。
> 量化口径：下表显存为 **Q4_K_M** 估算，实际随上下文长度与并发浮动。

## 二、按显卡档位推荐

- **无独显 / 核显（共享内存）**：Qwen2.5-3B、MiniCPM3-4B、Gemma-2-2B（CPU 可跑，较慢）
- **6–8 GB 显存**：Qwen2.5-7B、DeepSeek-R1-Distill-7B、GLM-4-9B
- **12–16 GB 显存**：**Qwen2.5-14B / Qwen3-14B（12–16GB 卡默认）**、DeepSeek-R1-Distill-14B
- **24 GB+ 显存**：Qwen2.5-32B、DeepSeek-R1-Distill-32B（最强本地脑）

## 三、本项目默认设定

- 默认：**Qwen2.5-14B**（12–16GB 卡）。**用户当前为 10GB 显存 → 改跑 Qwen2.5-7B / Qwen3-8B（见第五节）**，14B 占 ~9GB 太挤，会压到桌宠形象/语音栈。
- 低配机：**MiniCPM3-4B**（牺牲一点质量换"能跑"）。
- 显存不足时：在 `conf.yaml` 把 LLM endpoint 切到 DeepSeek-V4-Pro API（按 token 计费，非本地）——**仅作回落，不默认**。
- 与方案总成 §4 一致：本地优先，API 仅作降级。

## 四、配套本地 AI（非 LLM 大脑）

- **STT（语音识别）**：sherpa-onnx / FunASR(SenseVoice)，本地 CPU 实时。
- **TTS（语音合成）**：Edge TTS（系统级）、GPT-SoVITS（克隆声线，本地）。
- **VAD（打断检测）**：Silero-VAD，本地。
- **形象渲染**：Live2D Cubism5 / VRM（借 AIRI 集成范式，不自建渲染引擎）。

## 五、10GB 显存专用（用户当前硬件）

10GB **不要上 14B**（权重 ~9GB，几乎占满；桌宠还需显存/内存跑 Live2D 形象 + STT/TTS，会挤爆）。**7B 档留 ~5GB 余量最稳。**

| 模型 | 最低显存(Q4) | 中文 | 工具 | 特点 |
| --- | --- | --- | --- | --- |
| **Qwen2.5-7B**（推荐） | ~4.5 GB | ★★★★★ | ✅ | 全能均衡，10GB 首选 |
| Qwen3-8B | ~5 GB | ★★★★★ | ✅ | 新一代，带思考模式 |
| 小米 MiMo-7B-RL | ~5.3 GB | ★★★★ | ✅ | 推理强（数学/代码），小米开源 MIT |
| DeepSeek-R1-Distill-7B | ~4.5 GB | ★★★★ | ✅ | 推理链强 |
| GLM-4-9B | ~6 GB | ★★★★★ | ✅ | 中文最强档，留 ~4GB |
| MiniCPM3-4B | ~3 GB | ★★★★ | ✅ | 最省显存，余量最大 |

- 小米 MiMo 还有 **MiMo-VL-7B**（视觉，可看屏幕/图）、**MiMo-Audio-7B**（音频理解）同尺寸可选。
- **KIMI 不能本地跑 10GB**：K3 为 2.8T MoE、权重 1.56TB，官方需 64+ 加速卡集群；K2.6 也要 8 卡。Ollama `kimi-k3:cloud` 仅转发到月之暗面服务器（非本地、数据出设备）。KIMI 只能作 API 回落，牺牲隐私，不纳入本地大脑候选。
