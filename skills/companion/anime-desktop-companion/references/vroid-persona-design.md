## 2. VRoid Studio 分模块步骤

### 2.1 基础设置
- 体型预设"幼年/小个子"：身高最低档、头围调大、**肩窄、四肢纤细**（手动把臂/腿粗细滑条拉低，对照立绘的纤细感）。

### 2.2 脸部
- 圆脸 + 婴儿肥；眼睛选大眼型 → **瞳色改雪白微灰 #EDF2F5**（白色瞳孔+深灰高光），瞳孔大小+、高光星形；
- 眉毛细微上扬；小嘴；腮红淡粉。

### 2.3 头发（关键）
- **双马尾发型预设**（长双马尾到腰），发色：**上半白 #FFF**，用发梢渐变功能把**中段到发尾渐变粉 #FFB6C1**；
- 齐刘海；**发饰放天蓝色千纸鹤**（找不到用蓝蝴蝶结/自建折纸鹤形）。

### 2.4 服装
- 洛丽塔裙模板 → 改粉白多层蛋糕裙 + 草莓图案（贴图可自己加）；
- **过膝袜**：用袜装模板，渐变白→灰黑（上部白、下部灰黑）；袜口加**白色蕾丝花边**；
- 裙摆短一些，露出**绝对领域**；白丝顶部留白。

### 2.5 特效/表情
- 头发上加**金色星星发饰/粒子**（配饰模板或自建小星形）；
- 表情：星星眼（高光星形）、毒舌笑、waku 惊讶嘴（保留）。

## 3. 导出 VRM 并接入 Harness
1. VRoid Studio → 导出 `.vrm` → `runtime/p0/avatar-models/zhezhi/zhezhi.vrm`；
2. `conf/conf.yaml`：
   ```yaml
   avatar:
     provider: vrm
     model_path: ./avatar-models/zhezhi/zhezhi.vrm
   ```
3. 渲染：`@pixiv/three-vrm`（Web）或借 AIRI 的 VRM 渲染集成（不装底座）；
4. `persona.yaml` 的 `appearance` 已存定稿描述，无需改。
